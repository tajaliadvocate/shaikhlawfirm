# Taj Ali Advocate — Shaikh Law Firm

Independent static website prepared for Vercel. No build dependencies required.

## Publish
Extract the ZIP and import its files into a GitHub repository, with index.html at the repository root. Import the repository in Vercel. Choose Other, use no build command, and serve the root directory. Alternatively run `npx vercel --prod` from the extracted directory and sign in when prompted.
